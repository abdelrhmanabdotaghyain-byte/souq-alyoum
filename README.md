# سوق اليوم

## التشغيل على الاستضافة (3 أوامر بس، من غير تعديل أي ملف .env)

```
npm install      # بيثبّت الموقع والسيرفر مع بعض
npm run build    # بيبني الموقع
npm start        # بيشغّل الموقع + السيرفر على نفس العنوان
```

- محتاج Node.js إصدار 22.13 أو أحدث.
- السيرفر بيقدّم الموقع نفسه، فمفيش CORS ولا عناوين تتظبط.
- **البيانات** (الحسابات، الطلبات، صور التحويل) بتتحفظ في `server/data`. لازم الاستضافة تكون ليها **قرص دائم** (VPS، أو Railway/Render مع Disk...). الاستضافات اللي بتمسح الملفات مع كل نشر هتمسح الحسابات.
- مفتاح تشفير الجلسات بيتولّد لوحده أول تشغيل ويتحفظ في `server/data/jwt.secret`.

## التطوير على جهازك

```
npm run dev:server     # نافذة 1: السيرفر
npm run dev            # نافذة 2: الموقع (بيحوّل /api للسيرفر لوحده)
```

## حاجات بتعدّلها لو حبيت (كلها في ملفات الكود)

- أرقام المحافظ والشحن ورسوم الدفع عند الاستلام: `src/shared/store.js` (أي رقم فيه XXXX بيتخفى لحد ما تحط الرقم الحقيقي).
- الكوبونات: `server/orders.js` (WELCOME10 / SOUQ50 / VIP15).
